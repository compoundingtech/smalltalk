# Test Writing eval for st2

This eval tests whether a Codex team writes regression tests instead of coverage theater.

The developer can change tests only. The supervisor owns no product repository.

A held-out battery plants 12 mutations. The added suite must kill at least 10 mutations.

Run it with `st2 eval ./evals/st2/test-writing`.
