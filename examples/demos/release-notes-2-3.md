# Copperwren 2.3

## New

- **Rainfall chart.** Each station's dashboard shows the last 30 days of rainfall, in inches, behind the `new-charts` flag.
- Stations that miss three readings in a row show a grey dot instead of a stale value.

## Fixed

- The wind rose no longer flips north and south on stations below the equator.
- Exported CSV files name their columns in the station's own units.

Copperwren is an invented product used in st's example demos.
